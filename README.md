# IPTV Lite

Android-only lightweight IPTV player extracted from the IPTV scope of Debrify.

## Scope
- M3U playlists
- Xtream Codes
- Live TV
- Movies / VOD
- Series and episode playback
- Lightweight ExoPlayer-backed playback through Flutter `video_player`
- Saved source credentials

Excluded from this branch: debrid providers, torrent search, trackers, cloud storage, Stremio catalogs, desktop/Apple platforms, downloads, recording, WebDAV, YouTube and other non-IPTV features.
